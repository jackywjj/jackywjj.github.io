2026.09.09 读书笔记

重读《DOOM启世录》，我突然理解了AI时代

上个星期，我重新拿起了《DOOM启世录》。这是大卫·卡什纳（David Kushner）的 《Masters of Doom》，讲的是约翰·卡马克（John Carmack）和约翰·罗梅洛（John Romero），以及 id Software 如何做出 DOOM 和 Quake。三百多页的书，可能是因为共鸣太强，我差不多花了一周看完。

这不是我第一次读这本书，但这次的感觉明显不一样。以前看，更激动于天才程序员、游戏引擎和创业故事；现在再看，想到的却是团队、价值观，还有一个技术时代到底是怎么被推开的。

那个从 DOS 里冲出来的时代

上世纪九十年代初，家用主机上已经有马里奥这样的流畅卷轴游戏，PC 游戏却还在努力突破硬件限制。卡马克擅长钻到技术最底层，把普通电脑的性能一点点榨出来；罗梅洛既会编程，也更敏感于关卡、体验、传播和玩家到底觉得爽不爽。

他们在 Softdisk 共事，后来与汤姆·霍尔、阿德里安·卡马克一起创立 id Software。按 id Software 的作品年表，DOOM 于 1993 年推出，最初的版本面向 DOS。它当然不是历史上第一个 3D 游戏，但它让大量普通玩家第一次感受到：电脑屏幕像是突然向里面打开了一个世界。

我大约在 2000 年前后接触电脑，也玩过 DOOM、雷神之锤这些。后来很多第一人称射击游戏，都能看到 id 引擎和那套设计思想留下的影子。对当时的我来说，这些游戏不只是娱乐，它们也在告诉我：写代码，真的可以创造一个过去不存在的世界。

做出事的，从来不只是一个天才

书里让我印象最深的，并不是某段神奇代码，而是早期那支团队。他们白天拼命做游戏，晚上一起玩《龙与地下城》，卡马克经常担任地下城主。每个人的能力并不相同，但在那个阶段，他们都想把最好玩、最酷、以前没人见过的游戏做出来。

这让我越来越相信，复杂产品很难靠一个人完成。技术、设计、美术、产品和商业必须接在一起。所谓价值观一致，也不是所有人性格一样、意见一样，而是大家对产品方向、质量标准和做事方式有基本共识。可以争，但最后得往同一个地方走。

DOOM 成功以后，两位约翰的方向慢慢分开了。罗梅洛更靠近游戏设计、玩家、名声和商业，卡马克则继续钻进引擎和底层技术。到 Quake 前后，这种分歧已经很难调和，罗梅洛最终离开 id。

《Quake III Arena》是 id Software 1999 年推出的作品。罗梅洛离开 id 后参与的项目 《Daikatana》 由 Ion Storm 开发，于 2000 年推出。

谁对谁错其实没有那么重要。更重要的是，一个团队一旦失去共同方向，再强的个人能力，也很难继续保持原来的合力。

技术与设计可以不同，但最后要朝同一个方向走。

从 DOOM 到 AI，我又看见一次时代切换

重读这本书，最打动我的还是那种时代切换的感觉。从二维卷轴到高速的第一人称空间，从一张张画面到一个可以进入、探索和互动的世界，那种变化非常鼓舞人心。

今天的 AI，也让我有类似的感觉。它不只是让某项工作快一点，而是在重新改变软件怎么做、产品怎么设计、团队怎么协作。历史当然不会简单重复，但窗口打开的时候，真正重要的不是围观，而是进去做点东西。

我很庆幸自己当年进入了计算机行业，也很庆幸今天还能赶上另一个技术快速变化的阶段。
