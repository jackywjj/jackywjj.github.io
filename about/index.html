About Me

Jacky Wu

大家好，我是 Jacky Wu，也就是玩AI的杰克。我曾任樊登读书企业版技术负责人和 IBM 架构师，有 20 年技术开发与企业数字化实践。

这个博客里有我早年写下的 Java、Linux、数据库和 Web 开发笔记。现在，我也在这里记录怎么用 AI 做实验，怎么把软件工程的方法用到产品和运营里。写到一个方法时，我会尽量交代当时遇到了什么问题、具体怎么做，以及哪些地方还没验证清楚。

在家育种业工作时，我参与了生产和育种数据的整理、分析与报表工作。刚接触这个行业的时候，我以为把系统和数据理顺就能解决大部分问题。真正往下做，才发现得先弄懂现场怎么记录、指标怎么算，以及这些数据能回答什么问题。那段时间，我补了数量遗传学和统计方面的基础，也用 R 和 Python 跑了一些例子，把学习过程整理成了一份双语自学教程，分享给同样从计算机背景入门的朋友。

我也在运营「玩AI的杰克」的公众号和视频号。公众号适合把一次工具实践写透，视频号则让我练习在几分钟里讲清楚一个技术问题。我把生成式 AI 用到选题、写稿、配图、配音和字幕里，也用它做小工具原型、整理可以重复使用的工作流。这些实践让我慢慢摸清了哪些环节可以交给 AI，哪些还得自己回看。像文章里的出处、教程里的操作步骤、成片里的字幕，我都会按最终版本再过一遍。

如果你正在解决类似的问题，欢迎到 GitHub 找我交流。
